# Globs are repository-relative, use forward slashes and match case-sensitively. '*' matches

# matches. AGENTS.md, CLAUDE.md, docs/writing-principles.md and this file must stay selected.
#

# assembled from fragments, and required verbatim third-party text that contains one is excluded
# by a literal '- <path>' line whose comment names the reason and the authorizing decision, after
# which review preserves that text as it preserves LICENSE.
